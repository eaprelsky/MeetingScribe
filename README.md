# MeetingScribe

Небольшая утилита для Windows: записывает микрофон и звук компьютера, а после встречи расшифровывает оба потока через [RouterAI](https://routerai.ru/).

## Возможности

- Открывается из системного трея. Закрытие окна сворачивает программу в трей.
- Кнопка 📌 включает закрепление поверх других окон.
- Позволяет выбрать микрофон и устройство воспроизведения. Любой источник можно отключить.
- Сохраняет аудио и расшифровку в отдельную папку встречи.
- Позволяет изменить папку по умолчанию и скопировать готовую встречу в другое место.
- Продолжает прерванную расшифровку, пропуская уже обработанные фрагменты.
- Хранит API-ключ в диспетчере учётных данных Windows.

## Установка

Скачай архив Windows x64 из раздела [Releases](https://github.com/eaprelsky/MeetingScribe/releases), распакуй его целиком и запусти `MeetingScribe.exe`. Папка `_internal` должна оставаться рядом с EXE. Устанавливать Python для готовой сборки не нужно.

Утилита проверена на Windows 11 x64. Для записи используется WASAPI. При необходимости разреши классическим приложениям доступ к микрофону в параметрах конфиденциальности Windows.

## Первый запуск

1. Нажми ⚙ и вставь свой API-ключ RouterAI.
2. При необходимости измени папку встреч. По умолчанию используется папка «Расшифровки встреч» в системных Документах Windows.
3. Выбери микрофон и устройство, через которое слышишь собеседников.
4. Введи название встречи и нажми «Начать запись».
5. После встречи нажми «Остановить и расшифровать».

По умолчанию выбрана модель `openai/gpt-4o-transcribe`, язык `ru`. Модель и язык можно изменить в настройках. Пустое поле языка оставляет определение языка модели.

Кнопка «Сохранить встречу в…» копирует всю папку встречи в выбранное место. Исходная папка сохраняется. Существующие файлы и папки программа не перезаписывает.

Для завершения работы выбери «Выход» в меню значка в трее. Автозапуск при входе в Windows не включён.

## Что сохраняется

Каждая встреча получает папку с датой и названием. В ней находятся:

- WAV-фрагменты микрофона и звука компьютера длительностью около минуты;
- `meeting.json` с названием, временем начала и смещениями источников;
- `recognition.json` с результатами обработки фрагментов;
- `Расшифровка.md` с текстом, временными отметками и подписями источников.

Временные отметки обозначают начало фрагментов. Программа различает микрофон и звук компьютера. Отдельные голоса собеседников внутри системного звука она не разделяет.

Используй наушники: при работе через колонки микрофон может повторно записать голоса собеседников. Два несжатых стереопотока 48 кГц занимают около 1,4 ГБ за час.

## Повторная расшифровка

Если API недоступен, аудио остаётся на компьютере. Нажми «Открыть запись и расшифровать…» и выбери папку встречи с `meeting.json` и WAV-фрагментами.

Уже обработанные фрагменты повторно не отправляются. Чтобы расшифровать всю встречу другой моделью, сохрани копию папки и удали `recognition.json` в рабочей копии перед повторным запуском.

При смене аудиоустройства останови текущую запись, обнови список устройств и начни новую. При аварийном выключении компьютера последний незакрытый WAV-фрагмент может оказаться повреждённым.

## Данные и подключение

Запись начинается по нажатию кнопки. После остановки аудиофрагменты отправляются в RouterAI. Распознавание оплачивается с твоего аккаунта по тарифу выбранной модели.

Используется адрес `https://routerai.ru/api/v1/audio/transcriptions`. Соединение выполняется напрямую с проверкой сертификата HTTPS. Временные настройки прокси и сертификатов из окружения запуска не наследуются. Сети, требующие специального прокси, пока не поддерживаются.

Настройки лежат в `%APPDATA%\MeetingScribe\settings.json`. API-ключ хранится отдельно средствами Windows. Ключи, настройки, аудио и тексты встреч не входят в этот репозиторий.

Команда `MeetingScribe.exe --check-connection` проверяет распознавание одной секунды синтетической тишины через выбранную модель. Записи встреч при проверке не читаются. Запрос может быть платным. Результат без ключа сохраняется в `%APPDATA%\MeetingScribe\connection-check.json`.

## Запуск из исходников

Нужны Windows x64 и Python 3.13.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

## Проверки и сборка

```powershell
.\.venv\Scripts\python.exe -m unittest test_app -v
.\build.ps1
```

Сборка появляется в `dist\MeetingScribe`. Перед повторной сборкой закрой запущенный EXE через меню трея. Файл `MeetingScribe.spec` исключает конфликтующую библиотеку ICU из окружения сборки: Qt использует системную библиотеку Windows.

Автоматические проверки покрывают порядок фрагментов, продолжение обработки, сохранение аудио при ошибках API, смену WAV-фрагментов и изоляцию от унаследованного прокси. Для проверки реальной сети и записи нужны Windows, аудиоустройства и собственный API-ключ.
